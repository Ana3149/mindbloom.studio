# mindbloom-studio

Static website for MindBloom Studio. Plain HTML pages with no framework and no server.

## Pages

| File | What it is |
|---|---|
| `index.html` | Sensory & Routine Vault (home) |
| `berlin.html` | Berlin Relocation Vault — €350 VIP Advisory landing page (EN / PT-BR) |
| `terms.html` | Terms of Service (EN / PT) |
| `privacy.html` | Privacy Policy (EN / PT) |
| `legal-notice.html` | Impressum / legal notice |

## Styles

All pages use one stylesheet, `assets/site.css`, generated by Tailwind CSS from `src/styles.css`.
Fonts are served from `assets/fonts/`, so nothing is loaded from Google Fonts or a CDN.

After changing classes in any `.html` file or in `src/styles.css`, rebuild the CSS and commit `assets/site.css`:

```bash
npm install
npm run build
```

## Payments

The checkout button in `berlin.html` links to a Stripe Payment Link. It currently points to a **test-mode** link; replace it with the live-mode link before selling.

## Before going live

- Fill in the yellow `[...]` placeholders in `terms.html`, `privacy.html` and `legal-notice.html` (address, tax ID, hosting provider, session length, refund policy, governing law) and have the legal texts reviewed.
- Swap the Stripe test link for the live one.
